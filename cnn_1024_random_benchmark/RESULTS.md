# 测速结果及边界说明

## 测试配置

单张RTX5090，1024×1024输入，21帧，batch=1，随机初始化seed=123，不加载训练权重。网络使用BF16 autocast；光学转换保持FP32；推理时融合BatchNorm。最终SLM相位输出为FP32，本目录不是uint8输出测试。

卷积主干依据Pan/Lu补充材料第4.2节和图S6：3个前端卷积、3个两卷积残差块、1个输出卷积，卷积核全部3×3，隐藏通道16，输入输出通道2。论文没有明确给出BN及激活位置；当前实现使用BN/ReLU，不能声称与作者源代码完全一致。

## 历史实测

| 范围 | 普通推理 | CUDA Graph |
| --- | ---: | ---: |
| GPU内单帧 | 2.608 ms | 2.503 ms |
| GPU内21帧 | 54.77 ms | 52.56 ms |
| 含CPU上传下载单帧 | 2.855 ms | 2.736 ms |
| 含CPU上传下载21帧 | 59.95 ms | 57.46 ms |

每组为预热后10条序列的平均，原始时间记录见results.json。首次CUDA Graph捕获约419ms，单独记录；本测试输入下普通推理与图重放输出差异为0。

GPU内时间包含CNN推理、IFFT和取相位。CPU到CPU时间额外包含输入上传及每帧结果下载，使用预分配锁页内存，逐帧等待传输完成。结果不包含模型加载、预热、图捕获、输入图生成、初始目标相位生成、磁盘IO、网络访问服务器或SLM硬件刷新。

SLM输出尺寸为1024×1024；论文训练样本生成时的8192×8192 WGS网格不属于该CNN推理流程。本测试不生成WGS标签，也不验证随机参数的光学质量。

## 文件

- benchmark.py：测速入口，终端输出并覆盖当前目录results.json。
- cnn.py：独立网络结构，无外部实验目录依赖。
- optics.py：焦平面振幅/相位转换到SLM相位。
- README.md：服务器运行方式与依赖。
- results.json：一次历史实测的完整记录，重新运行前建议备份。

源码与文档不包含本机目录、公网连接地址、SSH端口或认证信息。
